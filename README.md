## 官方参数表里几个容易看漏的限制

第一个是“无限”这两个字的范围。普通会员的无限只指单张识别，批量识别每天 3 次、翻译每天 3 次这两条限制原封不动。买之前把版本对比表逐行看一遍，比看宣传语有用。

第二个是设备数量。两档授权都是可激活 5 台设备，这个数字对个人用户很宽松，手机加平板加电脑也就 3 台。但如果你打算和家人共用一个授权，或者换机比较频繁，就要把 5 台这个上限算进去。超出之后怎么解绑、能不能换绑，商品页没有写清楚，建议下单前问一句客服，不要凭猜测操作。

第三个是激活顺序。授权必须先在手机端激活，才能在电脑端登录使用。很多人在 Mac 上装完发现用不了，卡的就是这一步。流程不难，但顺序不能反。

第四个是电脑端的用法。在电脑上是通过 Wi-Fi 连接手机 App，然后在浏览器里上传、识别、校对、导出，它不是那种装完就能离线跑的独立桌面客户端。手机不在旁边的时候，这套流程会受一点影响。

第五个是准确率。官方介绍里写的是“准确度业内领先”，支持简繁中文、英、日等 10 多种语言，手写也能识别。这是厂商自己的说法，我没找到可以逐项核对的独立评测数据，所以不下结论。手写体、复杂表格、竖排古籍这类难度较高的场景，建议先用免费额度拿你自己的材料试几张，比看任何测评都准。

退款这块也要提前想清楚。荔枝卖的是虚拟授权码，商品页没有写明固定的退款窗口，能不能退、怎么退，下单前问客服确认最稳妥。不想承担这个不确定性，就先用免费版把需求验证一遍。
